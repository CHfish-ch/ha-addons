# Home Assistant Add-ons by CHfish-ch

This repository provides the following add-ons for Home Assistant:

- [Swiss Meteo Shade](swiss_meteo_shade/README.md) — weather-driven awning &
  blind automation from MeteoSwiss open data (Switzerland only)

## Installation

Add this repository to your Add-on Store in Home Assistant:

1. Settings → **Apps** (Add-on Store on older Home Assistant).
2. **⋮** (top right) → **Repositories** → paste
   `https://github.com/CHfish-ch/ha-addons` → **Add** → **Close**.
3. Refresh the store and install the add-on you want. See its own README
   (linked above) for setup and configuration.
